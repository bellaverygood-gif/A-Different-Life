## 3. 完整叙述

1988年，李建国出生在河南周口一个村子。家里五口人，父母、奶奶和一个姐姐。父亲农闲时去新疆摘棉花，母亲在家种小麦和玉米。他七岁上村小，教室的窗户没有玻璃，冬天用塑料布钉上。放学后他去地里拾麦穗，回家帮母亲烧灶。姐姐初中毕业后去县城服装店打工，过年带回来一袋水果糖。

2001年，他考进县里的初中，住校，每周带一罐咸菜。2004年，他考上高中，但家里拿不出学费，他跟着表叔去了深圳。第一份工作在电子厂，流水线一天站十个小时，工牌上写着他的名字和工号。第一个月发工资，他留下二百块，其余寄回家。

2006年，他在流水线上被机器夹到左手，休息了半个月，工厂只报了医药费。2008年，他当上拉长，管十几个人，工资涨了一点。2010年，他第一次坐高铁回郑州，给父亲买了一双皮鞋。2012年，他和同厂的河南姑娘结婚，租了一间带阳台的房子。2014年，儿子出生，妻子辞职带孩子。他一个人上班，每月寄钱回老家，剩下的存进一张银行卡。

2016年，他回到郑州，进了一家汽车配件厂。工资比深圳低，但能常回家。2017年，儿子上幼儿园，他把母亲从周口接来接送。2019年，他贷款买了一套小两居，首付是父母和姐姐凑的。2020年，父亲脑梗，他把父亲接到郑州住院，白天上班，晚上陪床。出院后，父亲半边身子不利索，母亲留在郑州照顾。他手机里存着父亲住院时的缴费单。

2021年，父亲第二次住院，他把准备提前还贷的钱拿了出来。2023年，配件厂订单减少，他被裁掉。他跑了半年网约车，又在物流园做分拣。2024年，他重新进厂，工资没有回到原来的水平。2026年，儿子职校毕业，进了郑州一家修理厂。2028年，妻子在超市找了份收银的工作，家里宽裕了一点。他不再买新衣服，工装一年四季穿。

2030年，儿子谈了对象。2032年，房贷还清，他把那张还款卡剪了。2035年，儿子结婚，他把小两居重新刷了一遍。2038年，孙子出生，他和妻子轮流去儿子家带孩子。2042年，他血压高，医生让他少熬夜，他还在上夜班。2045年，他还在做仓库管理员，腰不好，搬不动重货。2050年，他退休，在小区门口修自行车。儿子劝他别干了，他说再干两年。2055年，他搬去儿子家附近，老家的房子锁着。2058年，他去世，70岁。儿子在他的抽屉里找到一摞工牌，最早的一张是深圳那家电子厂的。他每年清明回周口上坟。他把旧工牌按年份排好。他没有坐过飞机。儿子教他用手机买票，他学了两次。他第一次坐地铁，是去郑州医院看父亲。他很少发朋友圈，也不太会。

## 4. 事业与财富判断

### 事业

- 类型：制造业流水线、汽车配件、仓储物流
- 路径：深圳电子厂 → 拉长 → 郑州配件厂 → 被裁 → 网约车/分拣 → 回厂 → 仓库管理员
- 成就：从普工做到拉长，供完房贷，把儿子养大
- 局限：没有学历，没有进入管理层的稳定通道；被裁后收入下降
- 评价：**平平无奇，但长期稳定，完成了家庭层面的积累**

### 财富

- 出生：贫困
- 婚后：温饱
- 2019：贷款买房，负债
- 2032：房贷还清
- 晚年：温饱，靠退休金和修自行车补贴
- 评价：**没有进入中产，但没有断供、没有欠债**
