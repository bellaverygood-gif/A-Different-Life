## 1. 产品定义

### 1.1 一句话

> 帮用户回到一个真实的选择现场，以旁观者视角看清当时为什么那样选，推演另一条路的代价，并带走一个今天可以做的动作。

### 1.2 用户真正的问题

用户不是在问：

> 我下一条人生该怎么过？

用户是在问：

> 我当初那个选择，到底是不是错的？  
> 如果是错的，是什么导致的？  
> 如果选了另一条路，会不会不一样？

### 1.3 产品不是什么

- 不是命运预测
- 不是心理咨询或治疗
- 不是“另一条路一定更好”的爽文
- 不是无限生成人生的内容库
- 不是给用户一个标准答案
- 不是收藏虚构人生的产品

### 1.4 产品定位语

> 给正在反复想“如果当初”的人，一次结构化的选择回看。  
> 不替你决定，只陪你把后悔翻译成理解。

### 1.5 市场判断

- 用户价值：高
- 使用频率：低到中
- 付费意愿：中
- 竞争：高（免费 AI、心理咨询、日记、课程）
- 传播潜力：中高
- 商业形态：更适合高价值小众产品 / 品牌产品 / 工作坊，而非大众刚需

结论：

> 值得做精益 MVP，值得小范围验证；  
> 不适合在产品没验证前投入重成本 AI 和复杂系统。

### 1.6 竞争与差异化

| 替代方案 | 用户为什么去 | 我们的差异 |
|---|---|---|
| 免费 AI 聊天 | 快、免费、什么都能问 | 六步结构、后见之明纠偏、选择档案、隐私 |
| 心理咨询 | 专业、有人陪伴 | 更轻、更便宜、可独自完成、非治疗 |
| 日记/手账 | 自由、私密 | 有结构、有旁观者视角、有下一步 |
| 星座/八字 | 情绪价值、解释感 | 不预测命运，回到真实选择与代价 |
| 人生模拟器 | 好玩、可分享 | 不做爽文，不做“另一条路一定更好” |

核心壁垒不是模型，而是：

1. 六步方法与错因分类
2. 选择档案的长期沉淀
3. 旁观者叙事与品牌审美
4. 本地优先的隐私信任

### 1.7 商业化假设

Phase 1 不做支付，不做会员。

后续可验证：

- AI 深度回看单次付费
- 选择档案导出/图卡
- 年度复盘工作坊
- 职业/城市选择课程
- 企业/高校 career workshop

低频产品不一定适合订阅，可能更适合：

> 单次付费 + 课程/工作坊 + B2B。

先验证留存和付费意愿，再决定商业化形态。

## 2. 目标用户与 JTBD

### 2.1 核心用户

- 24—35 岁，城市白领
- 正在职业、城市、关系或家庭的转弯处
- 有自我反思习惯
- 用过心理咨询、日记、MBTI、播客、知识付费
- 对“我当初是不是选错了”有持续的心理能量

### 2.2 首批切入场景

优先：**职业与城市选择**

- 要不要辞职
- 要不要换城市
- 要不要转行
- 要不要接一个机会
- 要不要为了稳定放弃一件事

原因：

- 决策边界更清楚
- 付费意愿相对更高
- 比婚姻/情感风险更低
- 更容易做案例与内容
- 可延展到职业咨询、工作坊、B2B

第二阶段再扩展：

- 关系选择
- 家庭选择
- 一次失败后的复盘

### 2.3 JTBD

> 当我反复想起一个选择、并觉得当初选错时，我想回到当时的处境，看清自己为什么那样选，推演另一条路的代价，从而停止用现在的信息审判过去的自己，并知道今天还能做什么。

### 2.4 非目标用户

- 正在经历严重心理危机的人
- 寻求医疗、法律、投资建议的人
- 希望 AI 直接告诉自己“选哪条路”的人
- 未成年人

## 3. 产品原则

1. **旁观，不审判**  
   不出现“你错了”“你太蠢了”“你本可以更好”。

2. **不同，不是更好**  
   另一条路只展示代价与收益，不承诺更幸福。

3. **过程错误 ≠ 结果不好**  
   必须区分：决策过程、结果、价值变化、结构限制。

4. **本地优先，AI 可选**  
   真实选择是敏感数据，默认本地保存。

5. **AI 是增强，不是产品**  
   AI 关闭时，核心流程仍然成立。

6. **用户自己得出答案**  
   产品提供结构、视角和问题，不替用户做决定。

7. **一次只回看一个选择**  
   不要求用户一次性交代整个人生。

8. **可完成**  
   单次回看控制在 10—15 分钟。

## 5. 核心流程：六步回看

### 5.1 总览

```text
选一个选择
→ 回到当时
→ 旁观当时的你
→ 拆错因
→ 走另一条路
→ 回到现在
→ 生成选择档案
```

每一步都自动保存草稿。用户退出后可以继续。

### 5.2 第 1 步：选择现场

目的：把“一个模糊的后悔”变成一个具体的选择。

字段：

- 这个选择发生在什么时候（年龄 / 年份 / 人生阶段）
- 当时你实际选了什么
- 当时你还有哪些选项
- 如果只用一个词命名它，叫什么

交互：

- 支持一句话标题
- 选项至少 2 个；允许“当时其实没有更好的选项”
- 允许“记不清”

完成条件：

- 有一个选择标题
- 选了什么
- 至少一个放弃的选项，或“没有其他选项”

### 5.3 第 2 步：当时的你

目的：把现在的判断和当时的处境分开。

问题：

1. 当时你知道什么？
2. 当时你不知道什么？
3. 当时你最想得到什么？
4. 当时你最怕失去什么？
5. 当时谁的意见影响最大？
6. 当时钱、家庭、身体、时间允许你做什么？
7. 当时你相信的“正确”是什么？

交互：

- 自由文本，限制字数
- 每题可跳过，但至少完成 3 题
- 提供示例，不替用户写

### 5.4 第 3 步：旁观当时的你

目的：用第三人称，把“我”变成“当时的他/她”。

系统输出（无 AI）：

- 一段 150—250 字的旁观者摘要
- 只复述用户提供的信息，不评价
- 结尾一句：

> 当时的你，不是在选一个正确答案，而是在选一个当时最能承受的结果。

用户可以：

- 确认“这就是当时的我”
- 修改摘要
- 补充一句“还有一件事”

### 5.5 第 4 步：拆错因

目的：回答“这个错的选择是什么原因导致的”。

#### 错因分类

| 类型 | 说明 |
|---|---|
| 信息不足 | 当时不知道后来才知道的信息 |
| 恐惧 | 害怕失去、害怕失败、害怕冲突 |
| 外部压力 | 家庭、经济、时间、他人期待 |
| 过度乐观 | 低估风险或高估自己 |
| 沉没成本 | 因为已经投入，继续加码 |
| 身份期待 | “我应该成为什么样的人” |
| 结构限制 | 当时根本没有更好的选项 |
| 价值观变化 | 现在的你变了，不是当时选错了 |
| 结果偏差 | 结果不好，但当时决策过程合理 |
| 说不清 | 需要继续探索 |

#### 无 AI 版输出

根据用户答案给出：

- 1 个主要假设
- 2 个次要可能
- 明确标注：

> 这不是诊断，只是一种旁观者视角。你可以不同意。

用户可以：

- 选择“更像这个”
- 选择“不是这个”
- 补充自己的解释

#### AI 版输出

只在用户点击“生成旁观者回信”后调用，详见第 7 节。

### 5.6 第 5 步：另一条路

目的：不是证明另一条路更好，而是看见它的代价。

必须回答：

- 短期得到什么
- 长期失去什么
- 谁会被影响
- 哪些问题不会因为换路而消失
- 你需要付出什么代价

无 AI 版：

- 提供结构化填空
- 用户自己写
- 系统只做归纳

AI 版：

- AI 生成“另一条路”的三种可能
- 明确标注“这是想象，不是预测”

可选动作：

> 把另一条路推演成一条时间线

跳转现有「推演」流程，带入当前选择背景。

### 5.7 第 6 步：回到现在

目的：把回看变成今天可做的动作。

问题：

- 这个选择今天还能修正什么？
- 不能修正的部分，你准备怎么与它相处？
- 如果给当时的你写一句话，你会说什么？
- 今天可以做的一个小动作是什么？

输出：

- 一句给当时的你的话
- 一个今天可做的动作
- 一个 30 天后的回看提醒（P1）

### 5.8 生成选择档案

档案结构：

1. 选择现场
2. 当时的你
3. 真正的原因
4. 另一条路
5. 今天还能做什么
6. 给当时的你一句话

操作：

- 自动保存到本地
- 可选“登录并备份”
- 复制全文
- 分享（P1）
- 删除
- 再次编辑

## 6. 功能需求

### 6.1 首页

必须：

- 主 CTA「回看一个选择」
- 次入口「我的选择档案」
- 二级入口「旁观别人」
- 合规文案

不得：

- 强制登录
- 出现“选一段人生，开始旁观”这类重复标题
- 把推演作为一级主入口

### 6.2 回看创建

- 游客可直接开始
- 自动保存草稿
- 单次回看可中断、可恢复
- 最多同时存在 3 个未完成草稿

### 6.3 选择档案

列表：

- 标题
- 时间
- 状态：草稿 / 已完成
- 最后编辑时间
- 是否已备份

详情：

- 完整六步内容
- AI 回信（如有）
- 编辑 / 删除 / 导出
- 登录后备份状态

上限：

- 本地最多 50 条
- 超出时提示删除旧档案

### 6.4 登录与云备份

原则：

- 本地可用
- 登录可选
- 不自动上传
- 用户主动开启备份

流程：

```text
完成档案
→ 本地保存
→ 提示“登录后可跨设备备份”
→ 用户选择登录
→ 绑定 openid
→ 同步档案
```

登录入口：

- 我的
- 保存成功后的提示
- 档案列表

不出现：

- 首次打开强制登录页
- 不登录不能使用

### 6.5 旁观别人

保留盲盒 / 剧本，但：

- 不保存虚构人生
- 不作为核心入口
- 不承诺回答“我的人生”
- 文案明确“旁观别人”

### 6.6 推演

- 从回看流程进入
- 默认带入当前选择背景
- Bazi 可选
- 不强制出生信息
- 不输出“命运预测”
- 文案定位为“另一条路的文化叙事视角”

### 6.7 隐私与删除

- 首次使用展示简短隐私提示
- AI 调用前单独同意
- 支持删除单条档案
- 支持删除全部本机数据
- 登录后支持删除云端档案
- 不把真实选择用于模型训练
- 不记录原始输入到日志

## 7. AI 需求（DeepSeek）

### 7.1 触发

只在用户完成六步后，点击：

> 生成旁观者回信

不自动调用。

### 7.2 单次输出

AI 只生成四部分：

1. 主要错因假设
2. 2—3 个当时没看见的盲点
3. 另一条路的得到与代价
4. 给当时的你一句话

不生成整篇人生故事。

### 7.3 输入

- 结构化摘要，不传原始长文
- 不传微信昵称、openid、手机号
- 人名、公司名、城市名做匿名化
- 最大 1200 中文字符

### 7.4 输出

JSON 结构：

```json
{
  "primary_pattern": "information_gap",
  "secondary_patterns": ["fear", "external_pressure"],
  "blind_spots": ["...", "..."],
  "alternative": {
    "gains": ["..."],
    "costs": ["..."],
    "unchanged": ["..."]
  },
  "letter": "...",
  "next_step": "..."
}
```

要求：

- 不超过 900 中文字符
- 不出现“你错了”“你应该”
- 不做诊断
- 不承诺结果
- 不编造用户没提供的事实

### 7.5 成本控制

- 每个档案最多 1 次 AI 调用
- 每个用户每天最多 3 次
- 相同输入哈希缓存
- 不提供 AI 聊天
- 不做多轮对话
- 输入 1200 字以内
- 输出 900 字以内
- 设置每月预算上限
- 预算耗尽自动降级为本地模板
- 只记录 token、耗时、模型、是否成功，不记录原始文本

### 7.6 超时与降级

- 云函数超时 30 秒
- 客户端等待 20 秒
- 超时/失败/预算不足：
  - 展示本地“旁观者框架”
  - 明确提示“这次没有生成个性化回信”
  - 不阻塞档案保存

### 7.7 安全

- 用户输入与 AI 输出都做内容安全检查
- 涉及自伤、危机、严重心理问题：
  - 停止生成
  - 展示求助提示
- 明确声明：
  - 不是心理咨询
  - 不是医疗建议
  - 不是命运预测

### 7.8 供应商

- DeepSeek
- Key 只放云函数环境变量
- 模型名可配置
- 预留 provider 接口，未来可替换

- 旧登录门禁：移除

## 9. 内容与文案规范

### 9.1 用词

使用：

- 一个反复想起的选择
- 当时的你
- 另一条路
- 代价
- 今天还能做什么

避免：

- 你错了
- 正确选择
- 命运
- 预测
- 改命
- 注定
- 诊断

### 9.2 关键文案

首页：

> 有些选择，不是忘了，只是一直没想明白。

回看入口：

> 不用写得很完整。先从一个你还会想起的选择开始。

旁观者摘要：

> 当时的你，不是在选一个正确答案，而是在选一个当时最能承受的结果。

另一条路：

> 另一条路不是更好，只是不同。

AI 回信：

> 这是一封旁观者回信，不是结论。你可以不同意。

免责声明：

> 本产品提供虚构叙事与自我反思工具，不构成心理咨询、医疗、法律、投资或命运预测建议。

## 13. 风险与待决问题

### 风险

1. 使用频率低，容易变成一次性产品
2. AI 回答泛化，用户觉得“像鸡汤”
3. 真实选择涉及隐私，用户不愿写
4. 情绪产品可能加重后悔
5. 微信审核对“心理/命理”敏感
6. Bazi 内容与“选择回看”逻辑冲突
7. AI 成本和超时
8. 免费 AI 的替代竞争

### 待决

1. 首批场景是否只做“职业/城市”？
2. 是否允许 18 岁以下用户？
3. 云备份是否默认关闭？
4. AI 每月预算具体金额？
5. Bazi 是否保留在 2.0，还是移到“旁观别人”？
6. 是否在 Phase 1 就做 30 天回看提醒？
7. Web 版本是否进入 2.0，还是后置？
