## 0. 先说结论

现在不是“再写几个页面”的阶段，而是：

> **M0 内容验证 → M1 盲盒重构 → M2 剧本免费层 → M3 付费/AI**

当前 1.2.6 仍然是：

- 强制微信登录
- 首页三个并列模式
- 盲盒 5 条旧长人生
- 剧本是七个条件生成
- 推演是独立 Bazi 模式
- 没有本地保存
- 没有图卡
- 没有情绪自评
- 没有数据说明

这与 2.0 目标结构不一致。

## 3. M1：盲盒 P0

这是 2.0 第一个真正要开发的产品模块。

### M1-01 数据层

- 把 18 张虚构人物卡转成结构化 JSON
- 字段：姓名、省份、出生年、去世年、性别、六维、时间轴、正文
- 不把长文写死在 WXML
- 不需要真实统计字段

### M1-02 首页结构

- 首页改成：盲盒人生 / 剧本人生
- 删除三个并列模式
- 删除独立“推演人生”入口
- 盲盒作为免费入口
- 剧本作为深度入口

### M1-03 登录改造

- 删除强制登录页
- 删除所有页面的 login guard
- 游客可直接抽、直接读
- 微信登录保留为后续云同步能力，不进入 P0 主流程

### M1-04 盲盒阅读

- 抽一生
- 骨架卡
- 完整人生阅读
- 六维总览
- 时间轴
- 落点句
- 再抽一次
- “看看自己的剧本”入口

### M1-05 情绪自评

- 更轻松 / 更沉重 / 没感觉
- 埋点
- “更沉重” < 20% 作为红线

### M1-06 本地保存

- 最近 20 条
- 只存本机
- 不做云同步
- 不做“收藏虚构人生”的旧逻辑

### M1-07 图卡

- 基础图卡：姓名/省份/生卒/一句落点/小程序码
- 客户端 Canvas 生成
- 不含个人信息
- 先做 2—3 个模板

### M1-08 数据说明页

- 说明全部为虚构人物故事
- 说明金额和事件是叙事设定
- 不是预测，不是真实统计

### M1-09 内容安全

- L0—L3 分级
- L3 不写
- L2 低频
- 不渲染疾病、死亡细节
- 文字克制

### M1-10 验收

- 18 张全部可抽到
- 每张能完整阅读
- 时间轴显示正确
- 图卡可生成
- 情绪自评可记录
- 本地保存可恢复
- 无登录也能用
- 无“营生”、无英文、无“你”

## 4. M2：剧本人生免费层

### M2-01 Bazi 引擎补齐

当前只有：

- 四柱
- 精确节气
- 北京时区
- 早晚子时

还缺：

- 农历/闰月输入
- 真太阳时
- 大运起运
- 命盘摘要
- 主题标签
- 30 组边界测试

### M2-02 输入页

- 出生日期（公历/农历）
- 出生时间（可不知道）
- 出生地（城市级）
- 性别
- 关注领域（付费层）
- 后悔的选择（选填，后续）

### M2-03 命盘摘要

- 四柱
- 日主与季节
- 五行分布
- 十神概况
- 阶段气质
- 主题标签
- 数据完整度

### M2-04 免费剧本

- 片段库拼装
- 不接 AI
- 300—500 字
- 片名 / 序章 / 三幕 / 不由星辰决定的一幕 / 落点
- 文化叙事声明

### M2-05 本地保存

- 最近 20 条
- 不做云同步

### M2-06 测试

- 30 组排盘样本
- 两个独立来源交叉核对
- 节气交界、子时换日、闰月、夏令时
- 抽样 100 份，禁用表述为 0

## 5. M3：AI / 选择改写（不做支付）

### M3-02 DeepSeek

- 云函数
- 单次调用
- 输入摘要，不传原文
- 输出结构化
- 超时降级
- 预算熔断
- 缓存与限流

### M3-03 选择改写

- 选择向量
- A/B 同次生成
- 分岔点前一致
- 差异清单：不变 / 改变 / 新增 / 消失
- 得到 / 失去 / 没有变
- 不系统性更好或更差
- 反刍防护

### M3-04 内容安全

- 输入输出检查
- 危机内容停止生成
- 求助提示
- 不作为心理咨询
