# 《中国数据登记表》模板

> 当前为空白模板，不填具体数字。  
> 没有完成来源、年份、许可证、署名核验的数据，不进入生产。

## 用途

为 18 张人物卡提供“中国省级/城乡数据骨架”，避免把虚构故事说成真实统计。

## 覆盖范围

M0 先做 6 个省份/区域，每个 3 张：

- 广西
- 湖南
- 河南
- 甘肃
- 黑龙江
- 广东

## 来源优先级

1. 国家统计局
2. 第七次全国人口普查
3. 各省统计年鉴
4. 卫健委/教育部公开数据
5. 其他公开来源，必须标明许可证

## 禁止

- 不使用来源不明的“网传数据”
- 不使用无法确认商用许可的数据库
- 不把全国平均数字当作某个人的精确命运
- 不在页面宣称“真实数据生成”，除非登记表完整

## 页面展示

如果接入数据，页面必须写：

> 根据公开统计生成的虚构人生，不代表真实个人，不是预测。

具体金额、职业、家庭事件均为叙事设定，不是统计事实。
