## 二、开发者收集的信息

### 1. 出生信息

- 收集内容：出生日期、出生时间、出生地点、性别
- 用途：在「剧本人生」中排四柱、生成文化叙事剧本
- 是否上传：默认只保存在本机
- AI 增强时：只上传匿名命盘摘要与选择主题，不上传出生日期、地点、原句
- 是否必填：出生日期必填；时间、地点、性别可不知道或不填

### 2. 阅读记录与情绪自评

- 收集内容：盲盒人物、阅读时间、最近阅读、情绪自评
- 用途：恢复最近阅读、判断内容是否让人更沉重
- 保存位置：本机
- 是否上传：不上传

### 3. 相册（仅写入）

- 用途：用户主动点击“保存图卡”时，把图片写入相册
- 权限：仅写入，不读取相册
- 是否上传：不上传

### 4. 不收集

- 微信昵称
- 微信头像
- 手机号
- 通讯录
- 精确位置
- 身份证号
- 病历
- 支付信息

## 三、第三方与 AI

- 当前版本不调用任何外部 AI；AI 入口、云函数和 openid 逻辑已移除
- 如后续启用 AI：
  - 通过微信云开发云函数转发
  - 只发送匿名命盘摘要、剧本骨架、选择主题与阶段
  - 不发送出生日期、地点、原句、昵称、openid
  - 不用于模型训练
  - 在页面单独说明并征得同意

## 四、保存期限与删除

- 出生信息、阅读记录、情绪自评、剧本：保存在本机
- 保存期限：直到用户清除小程序缓存、卸载小程序或更换设备
- 删除方式：
  - 微信 → 我 → 设置 → 通用 → 存储空间 → 小程序 → 清除缓存
  - 卸载小程序
- 当前没有云端账号，不涉及云端删除
