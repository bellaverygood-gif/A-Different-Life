## 3. 完整叙述

1975 年，周秋荷出生在湖南洞庭湖边一个种水稻的村子。家里五口人，父母、奶奶和两个弟弟。家里没有电，她借着灶火的光写作业。父亲读过几年书，晚上在油灯下教她认字。她七岁上村小，教室的墙是土坯的，黑板用木板拼成。

1990 年，她考上县里的师范学校。家里卖了一头猪，又向亲戚借了钱，才凑齐学费。她在师范住了三年，1993 年毕业，每月回家一次，带回一包粉笔头给弟弟写字。

1993 年，她回村小教书，教一年级和二年级，一个月工资买不了一辆自行车。她记得每个学生家的田在哪，放学后顺路去田里叫他们回来补课。有一年发大水，她把学生一个个送回家，自己的自行车被水冲走。她教了三十多年书，最远的教室在山上。

1996 年，亲戚给她介绍了县农机站的修理工。两人见过三次面，第二年结婚。丈夫第一次上门，带了一袋米和一只修好的闹钟。丈夫会修拖拉机，婚后住在学校分的一间平房。1998 年，她生下儿子。丈夫常年下乡，她一个人带孩子，晚上在灯下批改作业。儿子小时候在教室后面睡午觉，醒来就帮她擦黑板。

2000 年，村小合并，她被调到镇中心小学，每天骑自行车四十分钟。2003 年，她开始带毕业班，学生成绩在县里排到中游。2008 年，她拿到县里的优秀教师，奖品是一只暖水瓶。她没有当上校长，也没有离开讲台。她教过的学生里，有人回村当医生，有人去深圳做会计。

2010 年，母亲中风，她每周回村两次，给母亲擦身、洗头。她每月给母亲买药，药盒放在床头。2015 年，丈夫下岗，在镇上开了一个修理铺，生意时好时坏，欠过两个月房租。她用自己的工资供儿子读大学，家里的砖房一直没翻修。儿子上大学那年，她卖了两担稻，又向学校预支了半年工资。她的工资一直不高，但家里没有欠债。

2019 年，儿子去深圳做工程师，第一年寄回一台洗衣机。2025 年，她退休，学校返聘她两年。2030 年，她不再教书，在家里给邻居的孩子补课，收一点米和鸡蛋。退休后学校请她回去代课，她只收一半代课费。她不再教书后，村里人还叫她周老师。儿子结婚时，她把自己的一只银镯给了儿媳。

2036 年，丈夫去世。她搬到儿子家附近住，但每天回老屋浇花。2046 年，她的眼睛做了手术，看书要戴两副眼镜。她的膝盖不好，上楼要扶墙。2054 年，她去世，79 岁。学生从各地回来，送了一只花圈。她去世前，把那只暖水瓶送给了邻村的新老师。她的名字留在很多学生的毕业照上。

## 4. 事业与财富判断

### 事业

- 类型：乡村基础教育
- 路径：村小 → 镇中心小学 → 返聘 → 补课
- 成就：教了三十多年书，带过毕业班，拿过县优秀教师，学生里有医生、会计
- 局限：没有当校长，没有离开讲台，收入一直不高
- 评价：**有所成就，但职位和收入平平**

### 财富

- 出生：贫困
- 婚后：温饱
- 晚年：温饱偏上
- 资产：学校平房、后来盖的砖房、家电
- 负债：没有欠债，也没有大额积蓄
- 评价：**没有进入中产，但稳定**
