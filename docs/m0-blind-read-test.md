# M0 盲读测试方案

## 目标

在写代码前，验证三件事：

1. 读者能不能读完一条完整人生
2. 这条人生是否“有重点、有节点”，而不是流水账
3. 读完是更轻松、更沉重，还是没感觉

不是问“你喜不喜欢”，而是看：

- 能不能复述
- 能不能记住关键节点
- 会不会觉得像 AI
- 会不会想再抽一个
- 会不会想看自己的剧本

## 样本

18 张人物卡，先不测全部。

每个测试者读 **3 张**，来自不同省份、不同性别、不同寿命。

建议分配：

- A 组：韦秀兰、周秋荷、李建国
- B 组：马秀兰、赵海峰、陈晓梅
- C 组：覃小满、刘志远、周雨桐
- D 组：王秀云、陈浩、张建军
- E 组：李晓燕、孙丽华、王磊
- F 组：林建潮、黄嘉怡、黄志强

每组 2 人，共 12 人；至少完成 10 人、30 次阅读。

## 测试者

- 24—40 岁
- 男女各半
- 至少来自 3 个不同省份
- 不是产品团队成员
- 不提前解释产品定位

## 流程

1. 签署简短知情同意：匿名记录，不收集真实姓名
2. 一次只给一张卡，不同时展示其他卡
3. 阅读时间不限，记录实际用时
4. 读完后先不要讨论，先填问卷
5. 三张读完后，做 5 分钟访谈

## 问卷

### 每张卡

1. 用三句话复述这个人的一生。
2. 这个人做过哪三个关键决定？
3. 哪个节点改变了后面的生活？
4. 哪一句最具体、最像真实生活？
5. 哪一句最像 AI 写的？为什么？
6. 哪一段是空的、重复的、可以删的？
7. 读完是更轻松、更沉重、还是没感觉？
8. 你想再抽一个吗？
9. 你想看自己的剧本吗？

### 访谈

- 你觉得这是一条完整人生，还是一组事件？
- 你最记得哪一年、哪件事？
- 你有没有把某个数字当成真实统计？
- 如果只能保留一张卡，你选哪张？为什么？
- 你愿意把哪张卡发给朋友？

## 通过标准

| 指标 | 目标 |
|---|---|
| 三句话复述 | ≥ 70% 能复述 |
| 记住关键节点 | 平均 ≥ 3 个 |
| “更沉重” | < 20% |
| 想再抽一个 | ≥ 60% |
| 想看自己的剧本 | ≥ 50% |
| 觉得像 AI | < 30% |
| 把数字当真实统计 | < 20% |

## 不通过时怎么办

- 复述率低：删掉不推进人生的段落，补关键节点
- “更沉重”高：减少疾病、死亡、贫困细节，增加可控动作
- 想再抽低：换开头，第一段必须出现一个具体冲突
- 像 AI 高：删形容词、删比喻、删“不知道”句式
- 把数字当真实：页面标注“虚构人物，金额为叙事设定”，或去掉具体金额

## 测试后

只做两类修改：

1. 删空段、重复段
2. 补关键节点

不因为一个人说“不喜欢”就改方向。
