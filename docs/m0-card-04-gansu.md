## 3. 完整叙述

1972年，马秀兰出生在甘肃定西一个山村。家里住土坯房，水要从窖里打。父母种小麦、土豆和胡麻，靠天吃饭。她上面有一个哥哥，下面有一个妹妹。冬天她的手背裂口，母亲用羊油给她抹。她七岁上村小，教室的桌子是土台子，她拿树枝在地上练字。她小时候最怕去窖里打水，绳子磨手。

1988年，她考上县里的卫校。家里卖了一头驴，哥哥去工地干活，才凑齐学费。她在卫校住校，每个月回家一次，背一袋土豆回学校。1991年，她到乡卫生院报到，先做护士，后来跟着老医生学接生。第一次独立接生，她紧张得把剪刀掉在地上，捡起来又重新消毒。

1995年，她嫁给乡小学的老师。丈夫教语文，她值夜班，两个人常在一张桌子上批作业和写病历。1997年，她生下女儿。女儿断奶后，她把孩子交给母亲，自己回卫生院上班。她每天骑自行车走两个村，给孕妇量血压，给老人发药。女儿三岁那年，她把女儿带到卫生院值班室，睡在长椅上。她的药箱是帆布的，背带断过两次。

2000年，她第一次拿到执业助理医师证，工资涨了八十块。2003年，乡里设发热检查点，她穿着白大褂在路口守了一个月。2008年，地震波及陇南，卫生院在院子里搭帐篷，她给伤员换药，三天没回家。2010年，母亲查出高血压，她每周回村量一次血压，把药按天分好装在小塑料袋里。

2012年，她学会用电脑录健康档案，键盘上贴着手写的字母。2015年，乡卫生院合并，她成了全科医生，管三个村的慢病随访。她的工资不高，但家里盖了新房，买了摩托。2018年，她给村里最后一位麻风病老人送药，直到老人去世。

2020年，疫情来了，她在村口值守，给返乡的人测体温、登记。2022年，她退休，卫生院返聘她两年。2025年，她不再上班，在村卫生室帮忙。2028年，女儿结婚，她坐火车去兰州，第一次住酒店。

2035年，丈夫退休，两个人种了一院子的花。2038年，外孙出生，她去兰州带了半年孩子。2045年，她的腿不好，走远路要拄拐。2048年，丈夫去世，她搬回村里住。2052年，她去世，80岁。女儿在她的抽屉里找到一本随访笔记，最后一页写着村里老人的名字。她一辈子没有离开过甘肃。病人叫她马医生。她退休后还接电话。她记得每个村的水窖在哪。她不会开车，最远骑到镇上。她的手机里存着三百多个病人电话。她去世前一年，还帮邻居量过血压。她的白大褂洗得发白。她不爱拍照。她的墓碑上刻着“医生”两个字。她的药箱捐给了村卫生室。她走的时候，村里很多人来送。

## 4. 事业与财富判断

### 事业

- 类型：乡村基层医疗
- 路径：护士 → 接生 → 执业助理医师 → 全科医生 → 返聘 → 村卫生室帮忙
- 成就：接生、慢病随访、地震救援、疫情防控；村里人叫她马医生
- 局限：没有到大医院，没有高职称，收入不高
- 评价：**有所成就，但职位和收入有限**

### 财富

- 出生：贫困
- 婚后：温饱
- 中年：盖新房、买摩托
- 晚年：温饱，靠退休金
- 评价：**没有进入中产，但没有负债**
