## 1. 旁观者叙述规范

### 1.1 视角

- 第三人称：她 / 他 / 那个人
- 不出现“你”
- 不显性命名叙述者，不写“路过的人说”
- 旁观感来自写法，不来自一个角色

### 1.2 只写看见的

可以写：

- 手、鞋、袖口、秤、锅、灯、门、车票、药盒
- 听见的话、村里的传闻、广播、机器声
- 一个动作、一个停顿、一个物件的位置

不写：

- 她心里怎么想
- 他后不后悔
- 她是否幸福
- 这个选择对不对
- “如果当初……”

### 1.3 句式

- 每段 1–2 句
- 每段最多一个核心物件
- 每张卡 1–2 处“不知道”
- 每张卡最多 1 个比喻
- 不用“你”
- 不写“尽管……但她依然……”式励志句
- 不写“其实……”式安慰句

### 1.4 入口要有变化

不要每张卡都从“出生”开始写。

可用入口：

- 集市
- 窗外
- 院门
- 渡口
- 站台
- 工厂门口
- 诊所走廊

### 1.5 落点句三种

- 承认型：承认这一天是完整的，不总结一生
- 动作型：一个很小的动作，不解释
- 留白型：没有答案，也不追问

### 1.6 禁用词

岁月、时光、远方、悄然、仿佛、命运、不容易、可怜、坚强、命中注定、改命、必然、终于幸福。

### 1.7 自检三问

1. 删掉形容词后，这段还立得住吗？
2. 这句话是我看见的，还是我替他想的？
3. 换一个人物，这句话还能照搬吗？

### 样卡 01｜种地人

**骨架**

| 字段 | 内容 |
|---|---|
| 国家/地区 | 印度 · 比哈尔邦乡村 |
| 时期 | 1970 年代 |
| 性别 | 女 |
| 家庭 | 五口之家，务农 |
| 营生 | 种地人 |
| 数据状态 | 待登记表核验 |

**片段**

她出生在一个雨季很长的村子。接生的人把剪刀放在一只搪瓷盘里，盘沿缺了一小块。

她七岁开始跟母亲去田里。水桶比她的小腿还高，她走一段，停一段，把水桶换到另一只手。

村口的学校只开到五年级。她的课本用旧报纸包着，封面上写着她哥哥的名字。

她嫁给邻村一个种甘蔗的人。婚礼那天，她脚上的一只铜镯太紧，晚上才取下来。

丈夫后来去城里做建筑工。她一个人收甘蔗，把最重的那捆留在最后。田埂上有一台坏了很久的抽水机，没有人修。

她的儿子去了另一个邦。她坐在门口，把手机放在膝盖上，等它亮。屏幕上有一道裂痕，她用透明胶带贴过。

**数据事实（待核）**

在这个国家，农业仍是许多家庭的主要营生。

**落点**

村口的风把晾衣绳上的布吹干。没有人问她后来怎么样。

**内容分级**

L0 / 日常

### 样卡 02｜做工人

**骨架**

| 字段 | 内容 |
|---|---|
| 国家/地区 | 越南 · 红河三角洲工业区 |
| 时期 | 1990 年代 |
| 性别 | 男 |
| 家庭 | 父母、一个妹妹 |
| 营生 | 做工人 |
| 数据状态 | 待登记表核验 |

**片段**

他第一次进工厂时，门口的保安让他把工牌翻过来。照片上的人比他现在瘦。

车间里有一排缝纫机，声音从早到晚不停。他的工位靠近窗户，窗台上放着一只塑料饭盒。

他中午在机器旁边吃饭。饭盒里有时是米饭和煎蛋，有时只有米饭。他不挑。

妹妹的学费从他的工资里出。每个月发工资那天，他去邮局，把汇款单填得很慢。

他后来结了婚，妻子也在另一条生产线。两个人租了一间带铁门的房子，门口放两双鞋。

工厂加班的晚上，他会把自行车推到路灯下面，检查链条。链条上总有一层黑油。

有一年，工厂搬到了更远的地方。他没有跟去。工牌留在抽屉里，照片还是那张。

**数据事实（待核）**

在这个国家，许多工厂区离稻田不远。

**落点**

夜里工厂的灯还亮着。门口那排自行车少了一辆。

**内容分级**

L0 / 日常

### 样卡 03｜照看家的人

**骨架**

| 字段 | 内容 |
|---|---|
| 国家/地区 | 墨西哥 · 中部小城 |
| 时期 | 1980 年代 |
| 性别 | 女 |
| 家庭 | 母亲、两个孩子、一个在外地的兄弟 |
| 营生 | 照看家的人 |
| 数据状态 | 待登记表核验 |

**片段**

她家的窗台上有一只铁皮药盒。盒盖上有凹痕，里面分着早晨和晚上的药。

她母亲生病以后，她每天先去市场买菜，再回家煮汤。汤锅的把手用布条缠着，布条已经发黑。

她在门口摆过一张小桌，卖过一段时间的玉米饼。桌子是塑料的，桌脚下面垫着一块折起来的纸板。

她的兄弟去了北方。每年冬天，他会寄一张照片回来。照片背面写着日期，没有别的字。

她的女儿考上了城里的学校。她把女儿的书包洗了一遍，晾在院子里。书包的肩带断过，她用白线缝上。

晚上，她坐在母亲床边，手里拿着一把扇子。电扇坏了，她没有修。扇子是竹骨的，边上裂开一道口子。

**数据事实（待核）**

在这个国家，许多家庭照护由女性承担。

**落点**

窗台上的药盒少了一格。别的没有动。

**内容分级**

L1 / 艰难，但不渲染

## 3. 盲读问题

请把三张卡给 8–10 个目标用户读，不要先解释产品。

问：

1. 哪一句你最想截图？为什么？
2. 哪一句最像 AI 写的？为什么？
3. 读完是更轻松、更沉重，还是没感觉？
4. 你想再抽一个吗？
5. 你想看自己的剧本吗？
6. 有没有哪一句在替人物下判断？
7. 有没有哪一句像刻板印象？
8. 你能说出这个人靠什么生活吗？

记录原话，不要只记录“喜欢/不喜欢”。
