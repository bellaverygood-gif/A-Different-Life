# 平行人生 · 产品原型 V1

> 如果人生可以 DIY，你想过怎么样的一生？

一个以完整人生故事、路径推演与随机人生为核心的探索型产品原型。它不预测命运，也不替用户做决定，只把另一种可能摊开在你面前。

## 已实现

### 首页

- 首屏改为一个完整的“旁观者入口”：品牌、主文案、观察者说明和三种人生入口都在同一幅星门场景里，不再是脱节的 Header + 卡片。
- 三种入口是可以被悬停、聚焦、按下并播放穿越转场的“人生之门”，每扇门对应不同的光色、提示与体验目标。
- 首屏下方接“平行人生正在发生”六个具体故事卡片，含标题、摘要、阶段、匹配图片、共鸣和回应数据。
- 无顶部 Banner CTA、无“继续你的人生”模块、无传统底部导航、无首页固定主题堆叠。

### 三种独立流程

**剧本人生**

- 不需要出生时间。进入后先写下七个初始条件：出生家庭（金字塔顶端 / 普通小城 / 偏远小镇 / 随机）、童年（快乐 / 不幸 / 一般）、事业、爱情、财富、子女，以及一生走向（跌宕起伏 / 平平淡淡 / 先苦后甜 / 先甜后苦 / 其他自己写）。
- 根据这些条件组合出完整 0—80 岁时间轴、五个生活维度、优势与劣势、关键节点、机会与挑战，保留原有大纲目录。
- 报告带有“旁观中”状态条、阅读进度和章节式目录，并在结尾引导去推演或盲盒里继续看另一个自己。
- 支持修改人生设定、重新组合一版；剧本不再提供保存入口。

**推演人生**

- 进入后必须填写出生日期、出生时间、出生地与性别，前端按北京时间与节气交节时刻排出年、月、日、时四柱，并显示日主、五行分布、月令与出生信息。
- 以“站在命盘与选择之间”的视角，先输出妻、财、子、禄、寿五个维度的命盘解读，再进入选择推演。
- 问题和“来路”为选填。填写问题后，五维之后会出现“把这个问题放回命盘里看”的 double check：命盘回声、当前时间线、这个问题真正要判断的地方。
- 不填问题，则在五维之后引导写下一个遗憾或想改变的地方；只有写下节点后，两条时间线才展开。
- 支持修改关键节点，并明确展示修改前后的节点差异。
- 报告带旁观者状态条、阅读进度与跨模式继续探索入口；不重复铺陈无关的长条评分。

**盲盒人生**

- 五条来自不同年代、地域与处境的“另一个你”的时间线。每次抽取都会避开上一个自己。
- **一个盲盒 = 一条完整人生**，不是一组需要分别抽取的盲盒。
- 盲盒打开后直接进入一条写好的完整人生：从出生、少年、成年、转折、晚年，一直写到最后一页。其中的生命阶段只是这条人生的内部章节。
- 没有分支选择、没有多结局，也没有“拼结局”。盲盒的随机性来自“抽到哪一条人生”。
- 每一章都有具体年代、地点、人物、物件和完整叙事；SSR 只标出这一生里叙事亮度最高的一段，不代表成功或人生价值。
- 抽到人生与 SSR 时刻会保存在本机。

### 身份与互动

- 首次选择模式时询问昵称、探索方向、当前困惑，也可以直接以访客身份进入。
- Web 右上角个人入口可编辑宇宙坐标、查看看板统计、使用本机演示身份；小程序端使用微信登录。
- 支持故事共鸣与故事详情阅读。
- 个人星图展示故事共鸣、抽到人生与 SSR 高光时刻。
- 「我的星图」可打开完整隐私说明，并支持清除本机数据；也可直接访问 `#/privacy`。
- Web 记录保存在 `localStorage`；小程序记录保存在微信本地缓存。当前登录只做微信身份标记，跨设备同步尚未接入。

### 响应式

- 验证宽度：320、360、390、768、1024、1440。
- 移动端无横向溢出，模式卡片单列、故事卡片单列、报告适配窄屏。
- 图片、表单、报告正文在移动端保持可读；支持键盘焦点、Esc 关闭、焦点陷阱与减少动效偏好。

## 当前边界

- 故事内容由前端本地内容库与轻量生成逻辑组成，用于验证产品体验，不调用远程 AI。
- 剧本人生只使用家庭、童年与人生方向等初始条件，不读取出生时间。
- 推演人生按北京时间与节气交节时刻排四柱，未做真太阳时校正；五维内容为虚构叙事，不构成命理建议。
- 盲盒人生的 SSR 只表示这一段记忆的叙事亮度，不代表人生价值、成功程度或现实运气。
- 登录、互动与阅读记录均为本机演示数据，不连接服务器。
- 所有人生与人物均为虚构叙事，不构成职业、财务、医疗或关系建议。

正式产品可以把 `js/app.js` 中的 `buildScript()`、`buildPrediction()` 与 `drawBlind()` 替换为真实生成服务，同时保留现有的页面结构、状态流和交互。盲盒人生的五条完整时间线、30 个故事章节与 SSR 稀有度位于 `js/data.js` 的 `BLIND_LIVES`。
